# SpaceX Falcon 9 Landing Prediction 🚀

## Project Overview
This project analyzes SpaceX Falcon 9 launch data to predict whether the first-stage booster will land successfully.

## Data Sources
- SpaceX REST API
- Wikipedia (Web Scraping)

## Methodology
- Data Collection (API + Web Scraping)
- Data Wrangling
- Exploratory Data Analysis (EDA)
- Interactive Visualization (Folium, Plotly Dash)
- Machine Learning Models (Logistic Regression, SVM, Decision Tree)

## Results
- Best Model: Decision Tree Classifier
- Accuracy: 87.77%
