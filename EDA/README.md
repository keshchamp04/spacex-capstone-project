# Exploratory Data Analysis (EDA) 📊

## Overview
This section focuses on analyzing the SpaceX launch dataset to identify patterns, relationships, and key factors affecting the success of Falcon 9 first-stage landings.

## Objectives
- Understand data distribution and feature relationships  
- Identify trends influencing landing success  
- Generate insights to support predictive modeling  

## Files Included
- edadataviz.ipynb  
  → Performs exploratory analysis using plots and charts (matplotlib, seaborn)

- jupyter-labs-eda-sql-coursera_sqllite.ipynb  
  → Performs data analysis using SQL queries for filtering, aggregation, and insight extraction  

## EDA with Visualization
- Analyzed **Flight Number vs Payload Mass**  
- Compared **Payload vs Launch Site**  
- Evaluated **Success Rate across Orbit Types**  
- Studied **Payload Distribution across Orbits**  
- Observed **year-wise trend in launch success**  

## EDA with SQL
- Retrieved **unique launch sites**  
- Calculated **total and average payload mass**  
- Counted **successful vs failed landings**  
- Identified **first successful landing**  
- Queried missions based on **specific conditions (year, payload, landing type)**  

## Key Insights
- Launch success rate improves over time with increasing flight number  
- Payload mass and orbit type influence landing outcomes  
- Certain launch sites and orbits show higher success rates  

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)  
- SQL (for querying and aggregation)
